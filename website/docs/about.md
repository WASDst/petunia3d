# Sobre este caderno

O Petunia3D cresceu por várias ondas técnicas e migrações. Existem boas funcionalidades e algoritmos que devem ser preservados, mas também sobreposição de responsabilidades e abstrações históricas.

Este caderno separa explicitamente:

- estado atual comprovado;
- problemas observados;
- propostas em discussão;
- decisões aprovadas.

Nenhuma proposta vira arquitetura final automaticamente.
