# `crates/ui-slint/examples/`

Exemplos de execução autônomos para a interface Slint:
- `shell.rs`: Exemplo básico para testar a renderização do shell e loop da janela do Slint.
- `gallery.rs`: Galeria dos componentes base (`IconButton`, `Segmented`, `DropdownButton`, `PropertyRow`, `KeyHint`, `CommandSearchField`, `EmptyState`) para revisão visual; idioma por `PETUNIA_LANG`.
